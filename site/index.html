Humble links

Saves every download of a Humble Bundle library bundle page as signed URLs, one per line, for curl.

Install

Drag this link to your bookmarks bar:

Loading the bookmarklet…

Use

  1. Open a bundle page in your Humble library. Load it fresh (reload it if you got there by clicking around the library).
  2. Click the bookmark. A window shows how many links it has collected. When it finishes, a .txt file named after the bundle downloads and the window reports what was saved.

Download

./hb.sh ~/Downloads/humble-book-bundle-a-i-by-packt.txt

hb.sh downloads every file into a folder named after the list. The signed URLs expire 24 hours after the click.
